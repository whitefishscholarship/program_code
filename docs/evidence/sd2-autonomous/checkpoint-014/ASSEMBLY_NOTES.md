# Evidence handling and limits

The four initial Firecrawl requests returned INVALID_ARGUMENT before source
observations. Minimal supported parameters then succeeded. These are recorded
separately from the 23 public URL retrievals; no repeated 403/404 probing.

Draft previews included blank form labels, unrelated program/marketing text,
public biographical names and contact locators. One Reach Higher excerpt selection
extended past its intended FAQ boundary; this was detected by size inspection and
narrowed before ledger assembly or any commit. A Drive metadata response included
an identifier-bearing view query; the retained metadata omits that query. Final
artifacts exclude those values. Earlier output cannot be erased. Codex evidence
owner must narrow independent program boundaries and sanitize text, links and
metadata before each future output, and assess historical handling at later
authorized evidence/canonical/publication review. No excluded values are repeated
here and no raw full response is committed.

All artifacts are selected readable conversions. Original complete envelopes,
raw/native files, page images and complete tables/forms were not retained or
inspected. Author line concordance is against ephemeral in-session conversions;
it is not independent original fidelity or source-silence proof. A successful
response, cache miss or maxAge request never establishes current award facts.
The rejected requests requested maxAge:0; successful requests omitted maxAge.
Several successful observations were explicitly cache hits.

Oratory DOCX alias metadata is unexpected relative to its Docs URL, so its content
is held unread. Its other alias is a historical 2025 PDF; only readable text was
inspected. Version/checksums were unavailable in normalized metadata. Legion rules
returned only a heading despite status200, so national details remain held.
Three public PDFs and one native historical PDF yielded selected converted instructions only;
no applicant responses or personal field values were retained. Their complete
native/page/image/form scope remains unverified. No application action occurred.

All prior output, temporary custody, raw-batch rejection, NGPA timing, WAI/BLF
conversion/redacted identity, Herriges/DonK, WET403, Clerk visual, Davis recovery,
interim receipt and historical guard retention limits remain at original paths,
