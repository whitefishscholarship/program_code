## Certificate Scholarships:

This scholarship is for women currently enrolled or considering enrolling in a program that provides a certificate instead of a degree. Examples of recent awardees include cosmetology school, massage school, and other certification programs.

Application window is August 1 through September 15.  Applicants may apply only once for this scholarship aid.
